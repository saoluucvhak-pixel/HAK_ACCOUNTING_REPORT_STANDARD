# HAK Accounting Report Standard

Tiêu chuẩn trình bày và xuất báo cáo nghiệp vụ HAK.

## Phạm vi dự kiến
- Tiêu đề, thông tin đơn vị, kỳ báo cáo, bảng dữ liệu và tổng cộng.
- Quy ước định dạng ngày, số lượng, tiền tệ, căn lề, phân trang, chữ ký.
- Mẫu xuất Excel/PDF/DOCX phải được kiểm thử với dữ liệu mẫu.

## Trạng thái
Repository khởi tạo. Chưa có tài liệu chuẩn đã được xác minh; không coi nội dung này là chuẩn kế toán/pháp lý đã ban hành.
